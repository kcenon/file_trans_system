## Remaining acceptance items

- **#184:** TCP selection is real and unsupported QUIC fails explicitly.
  Enabled QUIC handshake/cleanup fails in the pinned network dependency.
  [Reproducer and boundaries](../protocol/TRANSPORTS.md).
- **#189:** The full production coverage gate reports **63.85%**, below 80%.
  Fully instrumented macOS TSAN reports two unresolved Asio-stack races in
  concurrent reconnects; no blanket suppression is installed. ASAN execution
  is not proof of leak freedom. [Gate evidence](REGRESSION_GATES.md).
- **#190 / integration boundary of #188:** Four 100-client upload runs each
  complete only 31 transfers; 69 receive-budget rejections remain. All 100
  downloads pass. The component pipeline admission fix does not make the
  separate 8 MiB runtime receive queue wait for space. [Raw measurements and
  code-level finding](PUBLIC_API_BENCHMARKS.md).
- Dedicated LAN qualification, a controlled regression baseline, live GCS,
  live AWS, Windows and remote GitHub workflow execution are unavailable.
  No successful component test or skipped service test substitutes for them.
- Authenticated chunks in #183 do not provide TLS 1.3 or authenticate every
  control message. Durable recovery in #186 is opt-in, with no automatic
  retained-state expiration; large-file recovery validates prefixes linearly.
